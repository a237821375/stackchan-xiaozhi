# 字体上游许可原文

此目录保留 `78/xiaozhi-fonts` 2.0.0 的 manifest 所列字族对应的官方版权和许可文本。完整下载地址、固定提交及每份文本的 SHA-256 见 [upstream-license-sources.json](upstream-license-sources.json)。

- `NotoSans*`、`NotoEmoji` 和 `NotoColorEmoji`：从 [Google Fonts 官方仓库](https://github.com/google/fonts/tree/7085eb89a950e85db5b166b7a58d414544b4140c/ofl) 各字族目录原样保存 `OFL.txt`，包含相应版权通知。CJK 文件保留 Adobe 的版权和 Reserved Font Name 声明。
- `MaterialSymbols-Apache-2.0.txt`：从 [Google Material Design Icons 官方仓库](https://github.com/google/material-design-icons/blob/737e3324305806514d7909874fa1818ae1808232/LICENSE) 原样保存 Apache-2.0 原文。此文本也可供理解字体组件元数据中的 Apache-2.0 声明；不将该声明推广到采用 OFL 的底层 Noto 字体。

这些原文取得于 2026-10-06。源文本的提交摘要仅固定许可来源。字体组件未包含源字体或相应原始通知，组件声明的来源仓库当时返回 404，故不能据这些文件确认其精确字体版本、全部来源或全部版权通知。详细范围与限制见 [表情资源来源说明](../stackchan-assets-provenance.md)。

CI 自动附带此目录，并复制构建中实际下载组件的可用许可和元数据。字体已由上游组件进行子集化、转换或合并；本项目资产生成器原样保留当前标准构建中的字体资源，并替换表情 GIF。OFL 文本对字体及衍生字体保持有效，仓库根 MIT 不更改字体原有许可。
