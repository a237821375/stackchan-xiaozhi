# StackChan 小智头部控制与讲话微动作设计

状态：历史设计归档。以下保留 2026-09-29 的原始设计，不代表当前实现或待执行任务；后续动作、摸头、跳舞与诊断已多次调整，当前状态以项目首页和板卡说明为准。

## 用户目标与保留行为

在现有 Xiaozhi v2.5.0 CoreS3 客户端上增加小幅点头、转头、抬头表达情绪，并允许 AI 根据“回正、抬头、低头、向左看、向右看”等自然语言控制头的位置。保留 xiaozhi.me 对话、绑定、Wi-Fi、黑底原厂风格表情和隐藏字幕。待机嘴巴不动，困困闭嘴；其他表情的动嘴进一步跟随讲话状态启停。

## 选择的实现方式

推荐：扩展当前小智固件的板级驱动，通过它已有的 MCP 工具接口提供动作能力；设备本地统一管理位置、情绪动作和限位。理由是保留现有云端对话路径，同时不要求 AI 实时控制每一帧。

备选：回到原厂固件可复用更多动作，但会改变当前平台接入；外部电脑代理控制会要求电脑持续在线。首版不采用这两个方案。

## 用户可见行为

- 回正：缓慢回到校准后的正面位置，停止此前的动作。
- 抬头、低头、向左看、向右看：移动到小幅预设位置并保持。左右统一采用机器人的自身视角，并在工具描述中声明。
- 再抬一点、再向左一点：在当前基准位置上做小幅增量，由设备检查目标范围。
- 点头、摇头：执行一次轻微动作，再回到本次动作开始前的基准位置。
- 别动、停止动作：取消队列并保持当前位置，暂停自动微动作；明确恢复动作后才重新启用。
- 讲话期间：围绕基准位置进行小幅动作，单次讲话最多两次，间隔至少四秒；短句可以完全不动。开心偏向轻抬头，思考偏向轻微转头，难过偏向轻低头。困困不触发讲话微动作。
- 明确位置命令优先于微动作；新命令取消过期动作。停止讲话后回到用户设定的基准位置，不擅自恢复正中。

## 接口和内部结构

板级总线驱动 → HeadController（串行调度、反馈、限位）→ MCP 工具与讲话/情绪事件。只允许一个任务访问舵机总线，避免两个动作互相争抢；音频和显示线程不等待完整动作完成。

AI 工具建议包括读取位置、选择预设姿态、有限范围的位置增量、点头/摇头、停止和恢复。首版不向 AI 暴露舵机原始寄存器、校准写入或连续旋转。工具返回 accepted/moving/completed/fault 等真实状态；入队成功不等同于实际到位。

云端通过现有 MCP 发现工具并发起调用。是否正确识别中文指令必须在设备接入 xiaozhi.me 后实测，不能仅凭固件注册成功判断功能完成。

## 硬件依据与活动边界

官方 hal_servo.cpp 使用 SCSCL 总线、UART1、1 Mbps、参数引脚 6/7，水平舵机 ID 1、俯仰 ID 2。移植前核对 begin 函数的收发参数顺序、电源使能以及 CoreS3 外设占用。禁止猜测普通 PWM 接线。

官方文档建议俯仰轴保持在 5–85°；官方源码还包含不同的软件限位与零点映射，不能把 UI 角度直接当作舵机原始角度。先核对旧备份中的校准值和设备反馈，建立映射；读取失败或映射未验证时保持动作禁用。不得把新启动位置默认为物理正面，不能开机猛回零，也不写舵机 EEPROM 或永久零点。

首轮验证每次相对移动约 2°，观察反馈和用户确认方向。确认映射后，正常微动作幅度 2–4°；位置预设相对安全正面位置约 10°，初版水平不超过正面左右 30°，俯仰限制采用官方安全范围内进一步收紧的校准区间，所有叠加动作再次限位。明确目标越界时拒绝并说明范围；自动微动作靠近边界时缩小或跳过。

通信超时、位置反馈无效或检测到阻滞时停止追加位置目标并进入故障状态；不持续尝试撞向目标。重新启用需先恢复有效反馈。动作校验使用底座 USB 接口并确保活动空间，避免头部 USB 线牵拉。

## 表情与讲话同步

保留现有风格，添加同情绪的静态嘴版本和讲话嘴版本。固件依据实际播放状态切换，而不是依赖 GIF 自己推测是否讲话；默认待机使用静止嘴，普通讲话使用 neutral 的讲话版本，困困两种状态均闭嘴。情绪变化可立即更新眼神，播放结束立即恢复闭嘴。这里实现讲话状态同步，不承诺音素级对口型。

## 实施与验证约束

固定 Xiaozhi v2.5.0 和对应 CoreS3 构建配置，保留 ILI9342C、Quad PSRAM 与当前分区布局。当前本地只有素材和固件备份，没有源码工程及完整 ESP-IDF 工具链；v2.5.0 的组件清单声明 ESP-IDF >=6.0.1，安装前核实官方构建版本，只准备一个兼容版本。

先在 Mac 验证角度映射、限位、动作抢占、停止行为和讲话结束事件，再编译固件。编译通过后保存当前完整 Flash 备份，核对新分区兼容性；不擦除 NVS、不覆盖绑定配置。先运行舵机只读诊断，再验证小幅移动，再开放 AI 工具与自动微动作。发现面板、音频、绑定或舵机异常时使用本机备份回退。

完成标准：原有对话和隐藏字幕正常；默认待机与困困嘴静止；讲话嘴可启停；五类姿态命令可由 AI 调用并反馈实际位置；点头动作回到指定基准；“别动”能够取消动作；超限和失联不会引起连续运动。
