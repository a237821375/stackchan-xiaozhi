# StackChan 机器人项目说明

本仓库的中文介绍已统一到 [README.md](README.md)。

我们开发的功能包括：

- 黑底原厂风格萌脸，21 种情绪、41 个 GIF 状态；讲话时动嘴，待机和困困闭嘴。
- 语音控制回正、抬头、左右看、点头和摇头，以及讲话微动作。
- 待机随机张望。
- 摸头显示喜欢表情、柔和抬头和轻点头，松手约 3 秒恢复。
- 跳舞时大幅左右、上下摆头，12 颗 RGB 灯切换颜色，结束恢复姿态并关灯。
- 舵机反馈、运动保护与通信诊断。
- 实验性直接语音插话：单台 K151 实测建议播放音量 60%；80% 时需提高说话音量。仍有识别错误与自动重启问题，见[插话说明](docs/stackchan-voice-interruption.md)。已有 alpha.2 Release 不包含该源码改动。

猫咪呼噜声尚未在实机实现，不属于已完成功能；相关运行代码、录音和专用测试已移除，摸头表情与头部动作保留。

完整的跳舞、头部动作、设备控制与触摸操作见[交互指令列表](README.md#交互指令列表)。

当前源码版本 0.1.0-alpha.2，另有未发布的插话改动；首次配置和旧版本升级均需阅读[本地校准指南](docs/stackchan-calibration.md)，缺失校准时头部不动。

请先阅读[项目首页](README.md)中的适配与完成情况。构建、资源和接口说明见[开发指南](docs/stackchan-development.md)。
